PHOTOS OFFICIELLES DE L'ÉTABLISSEMENT
=====================================

Pour afficher la photo d'un plat dans la carte, déposez simplement le fichier
image ici avec le nom du produit (identifiant « id » du plat) :

  public/photos/menemen.jpg
  public/photos/espresso.jpg
  public/photos/petit_dej_galista.jpg
  ...

La photo remplace automatiquement l'image d'illustration — aucun code à modifier.

Liste complète des identifiants disponibles dans src/data/menu.js (champ « id »
de chaque produit). Formats acceptés : .jpg (recommandé), .png.
